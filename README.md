# Mind-Care - IBM Project 🧠💚

An AI-Powered Mental Health Support Platform developed for IBM SkillsBuild Internship.

## 🌟 About Project
Mind-Care is designed to provide mental health support, mood tracking, and wellness guidance using AI.

## ✨ Features
- Mood Tracking & Analysis
- AI Chatbot Support
- Wellness Tips & Exercises
- Secure & User-Friendly Interface

## 🛠️ Tech Stack
- Python / Flask
- HTML, CSS, JavaScript
- IBM Cloud Services

## 🚀 How to Run
1. Unzip the project folder
2. Install requirements: pip install -r requirements.txt
3. Run: python app.py
